COMO RODAR O PROJETO (Altave OS)

1. Instalar dependências (na raiz):
   npm run install:all

2. Banco de dados:
   mysql -u root -p < DDL-DML/script.sql
   mysql -u root -p < backend/migrations/005_time_responsavel_e_total_os.sql
   mysql -u root -p < backend/migrations/006_listar_os_com_filtros.sql

3. Variáveis de ambiente:
   backend/.env.example  -> copiar para backend/.env  (configuração do MySQL)
   frontend/.env.example -> copiar para frontend/.env

4. Entrar com uma das contas iniciais listadas no README.

5. Subir a aplicação (dois terminais):
   npm run dev:backend     -> http://localhost:3000
   npm run dev:frontend    -> http://localhost:5173
